# How setup App for work 
**Auth + orm + DB + framework** 
- choose main framework for project 
  - for Example if fullstack choose Nextjs
  - if backend like honojs Express etc ...
- choose orm you will use 
  - like mongoose drizzle etc.. 
  - or raw sql 

- choose Auth way 
  - if JWT
  - or Auth.js or betterAuth or others  

- Configre Auth to ORM or DB 
  - to execute Auth to add user to DB

- start create your logic and tables
